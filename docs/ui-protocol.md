# Native UI ↔ fitvid CLI protocol

Native shells never parse FIT or call the Python library directly. They spawn the bundled `fitvid` binary.

## `fitvid inspect --format json`

```bash
fitvid inspect activity.fit --format json
```

Stdout: single JSON object.

| Field | Type | Notes |
|---|---|---|
| `sport` | string | |
| `session_index` | int | |
| `session_count` | int | |
| `session_start` / `session_end` | ISO-8601 | |
| `record_count`, `laps`, `pauses`, `events` | int | |
| `has_gps` | bool | Enables route-map toggle |
| `source_path` | string \| null | |
| `fit_device` | object \| null | `{label, manufacturer, product, …}` |
| `lap_times` | array | `{index, start_time, end_time}` for sync-moment picker |
| `fields` | array | Only **populated** metrics |

Each `fields[]` entry:

```json
{
  "name": "heart_rate",
  "label": "Heart rate",
  "category": "common",
  "count": 1190,
  "min": 90,
  "max": 185,
  "unit": "bpm"
}
```

`category` is one of `common` | `cycling` | `running` | `other`.

On failure, exit code ≠ 0 and stdout may be `{"error":"…"}`.

## `fitvid compile … --json-events`

NDJSON on **stdout** (one JSON object per line). Human logs go to stderr.

Events:

| `event` | Extra fields |
|---|---|
| `start` | `fit`, `videos`, `audios`, `dry_run` |
| `log` | `level` (`info`\|`warning`\|`error`), `message` |
| `range` | `start`, `end`, `reason`, `duration_s` |
| `progress` | `phase` (`sync`\|`cut`\|`overlay`\|`concat`), `clip`, `total`, `fraction` |
| `done` | `out`, `manifest`, `clips`, `ranges`, `dry_run`, `assumed_zero_drift` |
| `error` | `message` |

Exit `0` on success; non-zero after an `error` event (or crash).

Example:

```bash
fitvid compile \
  --fit activity.fit \
  --video cam.mp4 \
  --select /tmp/select.yaml \
  --overlay /tmp/overlay.yaml \
  --sync-config /tmp/sync.yaml \
  --out highlight.mp4 \
  --json-events
```

Uncovered selected ranges are **skipped** (logged as gaps). Compile fails only if **zero** clips remain.

All timestamps in inspect / sync / media probe are emitted in the **host machine local timezone**. FIT files are UTC on disk and converted to local on load. Video/audio `creation_time` wall clocks are interpreted as local. Device clock offsets are computed in that shared local timeline.

Native UIs label the action **Generate** (CLI command remains `fitvid compile`).

## `fitvid probe-media --group path…`

Groups files by recording-device identity (ffprobe tags). Stdout:

```json
{
  "devices": [
    {"id": "gopro-hero11", "label": "GoPro Hero 11", "files": ["/a.mp4"], "probes": […]}
  ]
}
```

## YAML generated by the UI

### `select.yaml`

```yaml
select:
  - type: videos   # default in UI: concat all videos by creation_time
# or
  - type: laps
# or
  - type: threshold
    field: power
    op: ">"
    value: 300
    min_duration: 5
```

`type: videos` (alias `all`) concatenates every `--video` file ordered by creation/start timestamp, burns FIT overlays where times overlap, and allows gaps vs the FIT session.

### `overlay.yaml`

```yaml
overlay:
  text:
    - field: speed
      format: "{value:.1f} km/h"
      position: [0.02, 0.88]
  map:
    style: route-only
    anchor: bottom-right
    width_px: 280
    height_px: 280
```

### `sync.yaml`

```yaml
sync:
  fit_generator:
    label: "Garmin Edge 840"
    fit_reference: "2026-09-05T20:38:35+00:00"
    watch_clock: "2026-09-05T20:38:35+00:00"
    wall_clock: null
  devices:
    - id: gopro-hero11
      kind: video
      label: "GoPro Hero 11"
      device_clock: "2026-09-05T13:38:40-07:00"
      files: [/path/a.mp4]
    - id: zoom-h5
      kind: audio
      label: "Zoom H5"
      device_clock: "2026-09-05T13:38:42-07:00"
      files: [/path/track.wav]
```

Offsets:

- `fit_offset = wall_clock - watch_clock` (or `0` if no wall clock / watch matches reference)
- `media_offset = spine_time - device_clock` where spine is wall clock if set, else FIT reference (+ fit offset)

## Wizard order (native UIs)

```
pickFit → syncFitGenerator → pickVideos → syncCameraClocks
  → pickAudio → syncAudioRecorderClocks → ready
```

1. Sync FIT watch (reference + watch readout + optional wall clock).
2. Pick videos → `probe-media --group` → enter each camera clock.
3. Pick audio (or Skip).
4. If audio present → group recorders → enter each audio recorder clock.
5. Compile with `--sync-config` (and `--sync none`).

## Locating the bundled CLI

| Platform | Path relative to app |
|---|---|
| macOS | `Contents/Resources/fitvid/fitvid` (+ `ffmpeg`, `ffprobe`) |
| Windows | `resources\\fitvid\\fitvid.exe` |
| Linux AppImage | `usr/lib/fitvid/fitvid` |
